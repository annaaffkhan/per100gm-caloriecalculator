# 🍽️ Per 100gm Calorie Calculator

A fast, simple, and intuitive calorie calculator designed for people who find nutrition labels confusing.

Instantly convert calories based on portion size and quickly log your intake into your favorite fitness apps.

---

## 🚀 Features

* ⚡ Real-time calorie calculation
* 🧮 Based on per 100g / custom serving
* 🍽️ Easy portion input
* 🎯 Clean and minimal UI
* 📱 Works on mobile and desktop
* 🔥 Lightweight (no frameworks)

## 🎯 How It Works

1. Enter calories from the nutrition label
2. Set serving size (default: 100g)
3. Enter how much you will eat
4. Instantly see total calories

---

## 💡 Why This App?

Nutrition labels can be confusing and annoying to calculate manually.

This app simplifies the process so you can:

* Save time ⏱️
* Avoid mistakes ❌
* Track food easily 🍽️
